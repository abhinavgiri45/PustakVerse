## 🌟 Key Highlights & Platform Architecture

### 🧠 1. GranthMind™ AI Universal Intelligence Suite (65+ Features)
- **🎨 AI Image Generation & Vision Art Studio**: Generate high-definition concept art, UI mockups, 3D renders, and illustrations with 1-click 4K PNG downloads.
- **▶ Live Code Runner & Interactive Sandbox**: Fullscreen code sandbox with responsive viewport switcher (**💻 Desktop 100%**, **📱 Tablet 768px**, **📱 Mobile 375px**).
- **⚡ Universal Smart Project Code Synthesizer**: Generates 100% complete, working, interactive single-file apps (e.g. Blinkit Quick-Commerce, Music Player, Expense Tracker, Whiteboard Drawing Canvas, Calculator).
- **🌐 Perplexity / Gemini-Grade Knowledge Sources & Citations**: Real-time topic-specific verified references with authentic domain favicons, SSL verification badges, and article excerpts (MDN Web Docs, Python Official Docs, GeeksforGeeks, Wolfram MathWorld, Khan Academy, Wikipedia Knowledge Graph, and Britannica).
- **📊 Mermaid.js Live Diagram & Flowchart Renderer**: Automatically detects `mermaid` code blocks and compiles interactive vector sequence diagrams and architecture flowcharts.
- **🔤 LaTeX Math Symbol & Equation Palette**: 1-click quick insert toolbar for $\int$, $\sum$, $\sqrt{x}$, $\pi$, $\theta$, $\infty$, $\frac{a}{b}$, $\le$, $\ge$, $\Delta$.
- **📊 Interactive Data Tables & CSV Exporter**: Auto-wraps markdown tables with instant sorting and 1-click **"📥 Export CSV"** download.
- **📽️ Markdown Presentation & Slide Deck Mode**: Turns multi-section AI explanations into interactive fullscreen slide presentations with keyboard arrow navigation.
- **🧮 Interactive Regex Lab & Matcher**: Live regular expression tester with real-time capture group chips.
- **🎧 Binaural 40Hz Focus Beats & Ambient Noise Synthesizer**: In-browser Web Audio API oscillator synthesizing 40Hz Gamma focus waves and soothing rain background sounds.
- **⏱️ Focus / Pomodoro Study Timer**: 25-minute focus intervals with break alerts and streak tracking in the sidebar.
- **⚡ Smart Slash Commands Palette**: Floating quick-command palette (`/code`, `/math`, `/explain`, `/summary`, `/quiz`, `/image`).
- **🧠 Code Explainer & Big-O Complexity Analyzer**: Instant Time & Space complexity ($O(n)$, $O(1)$) architectural breakdowns.
- **🧹 Code Beautifier & Minifier Tool**: Toggle between indented formatting and production minification.
- **⚙️ Custom AI Persona & System Directives Builder**: User-defined persistent instructions and behavior overrides.
- **✏️ Edit Past Prompt & Timeline Forking**: Modify previous queries to branch into distinct conversational timelines.
- **📁 Conversation Folders & Filter Chips**: Categorize sessions into **All**, **💻 Code**, **📚 Study**, and **🚀 Projects**.
- **📝 Interactive Practice Quiz Generator**: Generates multiple-choice quiz questions with instant automated grading and explanations.
- **🌐 Multi-Language Instant Translator**: Converts AI answers into Hindi, Spanish, French, German, Japanese, and more.
- **💾 Prompt Draft Auto-Recovery**: Preserves unsent drafts in browser storage across page reloads.
- **📥 Multi-Format Chat Export**: Export conversation histories to Markdown (`.md`), Plain Text (`.txt`), Printable PDF, or JSON.
- **📌 Pinned Answers Drawer**: Bookmark key solutions and code blocks for quick retrieval.
- **✨ One-Click Prompt Enhancer (`Ctrl+E`)**: Expands brief prompts into rich, high-impact engineering specifications.
- **🔍 Live In-Chat Message Search (`Ctrl+F`)**: Real-time keyword filtering across conversation history.
- **🎯 AI Specialist Mode Selector Tabs**: Topbar chips for Study, Coding, Creative Writing, Research, and Business modes.
- **🔄 Multi-Perspective Response Regenerator**: One-click regeneration options (*⚡ Shorter*, *📖 Detailed*, *💻 Alternative Code*).
- **🎨 Visual Theme Customizer**: Instant toggle between Dark Cosmos, OLED Black, Midnight Navy, and Cyberpunk.
- **🔤 Dynamic In-Chat Font Resizer**: Scale reading text smoothly between 12px and 22px (`A+` / `A-`).

### 📖 2. Immersive Digital Reading Experience
- **Interactive In-Browser PDF Reader**: Distraction-free viewer with zoom, width-fitting, and full-screen modes (<kbd>F</kbd> shortcut).
- **Ambient Color Themes**: One-click switching between **🌙 Dark Night**, **📜 Warm Sepia**, and **☀️ Day Light** modes.
- **Reading Progress & Auto-Bookmarks**: Remembers reading sessions and automatically resumes where the reader left off.
- **In-Viewer Notes & Journal**: Slide-out notes drawer to jot down takeaways, chapter summaries, and thoughts with 1-click **.txt export**.
- **🎧 Audio Voice Narrator (TTS)**: Web Speech Synthesis integration that reads book synopses aloud with estimated reading time calculations.
- **🔗 QR Code & Instant Book Sharing**: Dynamic QR code generator for instant mobile reading, plus one-tap sharing to WhatsApp, Telegram, and X (Twitter).

---

### 🔐 3. Enterprise-Grade Security Architecture
- **Two-Step Verification**: Email-based one-time security passcodes for logins, with permanent enforcement for administrative users.
- **Universal SMTP Delivery**: Multi-protocol direct SMTP (Port 587 STARTTLS / Port 465 SSL) with RFC anti-spam headers for instant worldwide delivery of OTPs.
- **Dynamic Account Security Health Shield (0–100%)**: Live score evaluating verified emails, Two-Step Verification, password hashing, and recovery question status.
- **Active Device Management & Remote Session Revocation**: Real-time IP address and user-agent tracking with one-click **"Log Out of All Other Devices"**.
- **Magic-Byte File Signature Validation**: Binary inspection for book (`%PDF-`) and image (JPEG, PNG, WebP) uploads, protecting against disguised malicious files.
- **Live Password Strength & Entropy Meters**: Real-time password feedback (*Weak &rarr; Moderate &rarr; Strong &rarr; Optimal*).
- **Brute-Force Attack Prevention**: Automatic 15-minute account lockout after 5 consecutive failed login attempts.

## 🛠️ Technology Stack

- **Backend**: Python 3.10+, Flask, SQLite (with WAL mode), Werkzeug
- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Glassmorphic Design System), JavaScript (ES6+)
- **APIs & Libraries**:
  - Google Gemini AI Models
  - Mermaid.js (Live Diagrams)
  - KaTeX & Highlight.js (Math & Code Rendering)
  - Google OAuth 2.0
  - Razorpay Payment Gateway
  - Web Speech Synthesis API & Web Audio API
  - QR Code Server API
- **Email Delivery**: Python `smtplib` / `email.mime` with TLS/SSL direct routing

## 🚀 Environment Setup (Owner / Authorized Development)

### 1. Repository Setup
```bash
git clone https://github.com/abhinavgiri45/PustakVerse.git
cd PustakVerse
```

### 2. Virtual Environment Configuration
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Dependencies Installation
```bash
pip install -r requirements.txt
```

### 4. Environment Variables
Configure `.env` in the root directory:
```env
FLASK_SECRET_KEY="your-super-secret-key"
EMAIL_ADDRESS="your-email@gmail.com"
EMAIL_PASSWORD="your-gmail-app-password"

# Google OAuth
GOOGLE_CLIENT_ID="your-google-client-id"
GOOGLE_CLIENT_SECRET="your-google-client-secret"

# Gemini AI
GEMINI_API_KEY="your-gemini-api-key"
```

### 5. Start Application
```bash
python app.py
```
Access locally at: `http://127.0.0.1:5000`
